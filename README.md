# Mai G77 Pocket

Android 手机上的 OpenGD77 写频工具。连着 OTG 线就能读写对讲机的码盘，不必开电脑。

## 能做什么

**读写**

- 读取整份码盘（128 KB），改完再写回
- 逐字节比对机器上的数据与手上的版本
- 备份成 `.g77` 文件，或从文件恢复

**编辑**

- 信道：新增、复制、删除、排序，频率/色码/时隙/功率逐项可改
- 区域：新建、改名、勾选信道（最多 80 条）
- 联系人：数字联系人、DTMF 联系人、通话组，三类都能建、改、删
- 设置：呼号与 DMR ID、开机文字、总体设置、侧键功能、提示音开关
- APRS：名称、SSID、坐标、经由、图标、发射频率，并可挂到信道上
- 主题：日间/夜间各 32 色，逐色修改
- 快捷短信：32 条，可新建与编辑

**工具**

- 卫星星历：拉取 CelesTrak 最新 TLE，只写常用的 8 颗，过境与跟星由机器自己算
- 呼号库：从 RadioID 下载 DMR ID 对照表，按地区前缀筛选（`46`、`460`、`461`），可逐条编辑后写入电台
- 屏幕画面：取回机器当前的屏幕，160×128，可预览或存成 PNG
- MCU ROM：读出固件本体（1 MB）存成 `.bin`，刷坏时可回滚
- 信道 CSV：导出成 Channels.csv 用 Excel 批量改，再导回来

## 支持情况

**已实机验证**：MD-UV380 / MD-UV390 Plus 10W，固件 `ebd7100`（2026-05-04 编译）

理论上适用于 OpenGD77 固件的 STM32 机型（GD-77、MD-760、MD-9600 等），但没有实机测试过。刷固件与射频校准这类会改动机器底层的功能，本项目一概不做，请用电脑版 CPS。

## 安装

到 Releases 下载 `MaiG77Pocket-x.y.z.apk` 直接安装。Android 7.0 及以上。

首次连接会弹 USB 权限请求，勾选「默认用于此设备」以后就不必再点。

## 自己编译

需要 JDK 17+ 与 Android SDK（compileSdk 37）。

```
./gradlew assembleDebug
```

发行版用项目里的固定密钥签名。密钥不进仓库，自己出包时生成一份：

```
keytool -genkeypair -v -keystore app/mai-cps-release.jks -alias mai \
  -keyalg RSA -keysize 2048 -validity 12000
```

然后在 `app/build.gradle.kts` 的 `signingConfigs` 里填上密码。
